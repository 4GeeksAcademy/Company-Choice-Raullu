### Corrección posterior al reporte del usuario

El usuario informó que **Enviar solicitud** aparecía en los pasos 1–3 y **Siguiente** en el paso 4. La lógica JS ya actualizaba la propiedad `hidden`, pero el HTML aplica clases Tailwind `inline-flex`, que pueden prevalecer sobre el estilo UA `[hidden] { display: none; }`. Para corregirlo se añadió en `styles.css` `[hidden] { display: none !important; }`, de forma que el atributo HTML `hidden` prevalezca sobre las utilidades `display` y funcione también para paneles y estados ocultos. No se cambiaron los archivos de implementación originalmente acotados ni los botones. Pendiente confirmar visualmente el flujo en navegador; se ejecutarán chequeos estáticos disponibles.
